# 메뉴 개편 검증

## 사전 상태

- 로컬 Chrome 보관함에 기존 기사 2건 확인: SKT 풀스택 ‘모두의 AI’, 제논 ‘모두의 AI’ 참여 선언.
- 이번 작업에서 개인 저장소 내용은 직접 수정하지 않는다.
- 실제 API 검색어 ‘모두의 AI’, 2026-09-01~2026-09-11: 기사·시간 흐름·CSV 95건 일치.
- 연관어 ‘소상공인’ 근거 기사: 선택 기간 총 60건, limit=3 시 3건 반환.

## 화면 확인 항목

- [x] 주간 브리핑 기본 화면, 데스크톱·모바일 최상위 메뉴 4개
- [x] 주간·월간 전환 및 이전 8월 선택
- [x] 월간보고서 `/report?month=2026-09` 링크와 개조식 해설
- [x] 주간 근거 링크 7건으로 중복 제거, 과제 후보 2개, 비교 지표 접힘
- [x] 통합 탐색 검색, 기사·시간 흐름·연관어 전환 시 검색어/기간 보존
- [x] 뒤로 가기, 새로고침, 기존 이메일 `?week=2026-W36#digest` → 해당 주 브리핑
- [x] 급상승·기관·교차와 개인 관심 주제/서버 설정 키워드 구분; 교차 최근 8주·3개 축 기사 100건 확인
- [x] 법령·규제 조회, 작업실 보관함·과제 탭
- [x] 기존 보관함 2건과 기존 과제 1건 유지
- [x] 모바일 메뉴·검색 폼, 페이지 폭 375=scrollWidth 375, 근거 영역 275=scrollWidth 275
- [x] 빈 결과 안내와 Enter 검색 제출
- [x] 사이드바 수집 상태 접힘 영역의 실제 소스별 현황
- [x] 최종 비동기 요청 경합·초기 연결 오류 보완 후 회귀: 실제 소스 지연 응답 4개 시나리오 통과, 초기 오류 배너 테스트 통과
- [x] Chrome에서 검색어를 키보드로 삭제 후 Enter: 빈 주제 안내, 근거 카드 숨김, 이전 그래프가 재등장하지 않음

## 발견 후 수정

- 연관어 보기에서 새 검색어 제출 시 이전 상태가 입력값을 덮던 문제: 수정 후 소상공인 그래프 15개 노드, 기간 내 근거 60건 확인.
- 탐색의 전역 검색창 중복: 탐색 화면에서는 숨김 확인.
- 모바일 보기 탭의 불필요한 세로 스크롤: 전용 모바일 스타일 수정.

## 한계

연관어 관계와 문서 수는 전체 수집 자료의 사전 계산값이다. 사용자가 선택한 날짜는 근거 기사 목록에 적용된다. 급상승은 표시된 주차, 기관·교차는 최근 8주 기준이다.
