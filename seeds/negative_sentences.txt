# 부정 시드 — "우리 팀 일이 아닌 것"의 프로파일
#
# 왜 필요한가 (실측 근거, 2026-08-30):
#   라벨 50건 측정에서 precision 0.240이 나왔다. 오통과 19건 중 17건이 `ai` 축
#   단독으로 걸린 항목이었다 — 엔비디아 M&A, 개발자 잡담, 코딩 도구 릴리스 같은 것들.
#   양성 시드만 쓰면 이런 항목도 코사인 0.55~0.60이 나와서 정답과 구간이 겹친다
#   (정답 0.576~0.659 / 무관 0.392~0.599). 임계값을 어디에 둬도 갈라지지 않는다.
#
#   그래서 "무관한 것"의 centroid를 따로 만들고
#       관련도 = 양성 centroid 유사도 − 부정 centroid 유사도
#   로 점수를 매긴다. 양쪽에 다 가까운 일반적인 AI 뉴스는 점수가 0 근처로 눌린다.
#
# 이 목록은 PLAN.md의 팀 정의에서 나온 것이지 특정 표본에 맞춘 게 아니다:
#   "(b) AI 서비스 개발(모델 학습·서빙)이 주력이 아니다. arXiv·최신 모델 릴리스는
#    (b) 팀에게 필수지만 (a·c·d) 팀에겐 대부분 노이즈다."  — PLAN §6
